# Кадр

Фоторедактор для iPhone: кадрирование, фильтры, коррекция, текст, стикеры и вырезание фона. Всё работает на телефоне, без аккаунта и сервера. Название рабочее.

Сделан с помощью набора Replica: функции и приёмы интерфейса изучены по публичным страницам, а код, иконка, цвета и тексты написаны с нуля.

## Как получить .ipa

1. Откройте вкладку **Actions** этого репозитория, запустите **Build IPA** (или просто сделайте push в `main`).
2. Через 5–10 минут файл `Kadr.ipa` появится в разделе **Releases** (тег `latest`).
3. Установите его на iPhone через [Sideloadly](https://sideloadly.io) или AltStore: они подписывают приложение вашим Apple ID.

Сборка идёт без подписи, поэтому сам по себе файл на iPhone не установится. С бесплатным Apple ID приложение работает 7 дней, потом его нужно переустановить. С платным аккаунтом разработчика срок не ограничен.

## Что внутри

- SwiftUI, iOS 17+, только iPhone
- Core Image для фильтров и коррекции, Vision для вырезания фона
- `project.yml` описывает проект для XcodeGen, `.xcodeproj` не хранится

## Что умеет

Кадрирование с пропорциями, поворот и отражение, 12 фильтров с настройкой силы, 9 параметров коррекции, текст с четырьмя стилями, стикеры (эмодзи и свои фигуры), удаление фона с заменой, отмена и повтор, экспорт в JPEG или PNG до 4096 px.

## Чего пока нет

Видео, коллажи, подписка, аккаунты, облако.
